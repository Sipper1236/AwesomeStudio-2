## Next slices

1. Add VST3 hosting and native plug-in editor windows; add block-based CLAP processing and plug-in latency compensation.
2. Add automatic audio input-latency measurement and take comping, plus native MIDI backends for other platforms.
3. Add Bezier fade handles, drum pattern chaining, and format-2 time-signature changes.
4. Add broader automation targets and platform packaging.
