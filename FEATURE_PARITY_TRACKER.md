# Feature parity tracker

Status describes the executable built by the repository's CMake target. Source files that are not compiled into the app do not count as implemented features.

| Area | Current status | Gap to a full DAW |
|---|---|---|
| Build and desktop shell | Working Qt 6 app with menus, docks, and saved window layout | Packaging, crash recovery, accessibility review |
| Piano roll | Per-clip full MIDI pitch range, straight/dotted/triplet snap grids, draw/move/resize/delete, Shift multi-select, velocity lane, MIDI-note undo/redo, editable clip length, quantization, exact single-note pitch/start/length/velocity/channel properties, key/scale highlighting and optional scale snapping, common chord insertion, optional same-track ghost notes, configurable up/down/up-down chord arpeggiation, and upward chord strumming | Multi-note property editing, arpeggiator velocity patterns |
| Instruments | Multiple polyphonic synth tracks with per-track ADSR envelopes plus a four-pad drum rack with synthesized voices or one assigned WAV sample per pad | Filters, oscillator stacks, presets, velocity layers, pad tuning/envelopes, plugin instruments |
| Transport | Arrangement play/stop, ruler click-to-seek, named arrangement markers, 20–300 BPM, common editable time signatures, song loop, off/1–4 bar count-in, accented metronome, count-in-aware audio recording | Punch recording, tempo maps |
| Projects | Versioned v20 `.aws` JSON save/open with atomic writes; stores up to eight Delay, Reverb, Compressor, or Low-pass Filter inserts per channel and 48 per project; v19 files retain their existing effect chains and gain default low-pass settings, v18 files migrate with empty effect chains; v1 projects migrate to a track and clip; v2–v9 files gain compatible meter/instrument/transport and empty automation defaults, v10 files gain default MIDI-channel values, v11 files gain an empty marker list, v12 files gain flat EQ settings, v13 files gain Master routing with no buses, v14 files gain no auxiliary sends, v15 files default audio fade curves to linear, v16 files retain their single track send and route buses to Master, and v17 files retain multiple track sends and nested bus routes; audio sources reopen from saved paths and missing or over-budget media stay offline; shared source cache with 512 MiB project memory cap | Autosave, backups, portable media packaging, broader migration tooling |

| Arrangement | Playlist with MIDI and WAV audio tracks, waveform regions, movable clips, left/right audio edge trimming, selectable linear/smooth/equal-power fade-in/out and undoable equal-power crossfades for overlapping regions, named ruler markers with undoable add/rename/remove and click-to-seek, editable MIDI clip lengths, and Standard MIDI File import/export (formats 0 and 1, PPQN timing) | Custom fade shapes, comping, MIDI format 2/SMPTE import |

| Mixer | Per-track level, pan, mute, solo, output routing, multiple post-track auxiliary sends, persistent three-band EQ and Delay/Reverb/Compressor/Low-pass Filter inserts; nested/group buses with level/pan/mute/solo, parent routing, multiple bus auxiliary sends, inserts, and peak meters; Master inserts; solo state propagates through parent and send routes; live per-track, bus, and master meters include arrangement playback and MIDI monitoring; routing cycles are rejected in the UI and normalized out of loaded projects | Parametric EQ curves, third-party effect hosting |
| Audio recording | Select an input device, record mono/stereo WAV takes, and add them as new Playlist audio tracks; uses count-in when output is available, works without output, supports standalone or during-take input monitoring to Master, and respects project and WAV size limits | Latency compensation, track-armed monitoring, punch recording, take comping |
| MIDI input | ALSA input device enumeration, polyphonic live monitoring for synth and sampled drum-rack notes, note recording, and channel-specific learnable CC mappings for master level, selected-track level/pan, and tempo on Linux; note on/off, overlapping same-pitch notes, count-in, loop timing, pattern assignment, and undo/redo | Native MIDI backends on other platforms, pitch bend, NRPN, and broader controller targets |
| Plugins and effects | Built-in per-track three-band EQ and persistent Delay, Reverb, Compressor, and resonant Low-pass Filter inserts on tracks, buses, and Master; realtime arrangement playback, WAV export, stems, and bounded effect tails | VST3/CLAP hosting, parameter automation, custom EQ curves |
| Automation | Per-track volume and pan keyframes with graphical Playlist lanes, click-to-add and drag-to-edit points, right-click/Delete removal, undo/redo, linear playback/render interpolation, and touch/latch recording from Mixer controls during playback | Trim mode, curved segments, plugin parameter automation |
| Collaboration and notation | Not implemented | Score view, collaboration, session interchange |

## Next slices

1. Add automation trim mode and plugin parameter automation with plugin hosting.
2. Add native MIDI input backends for other platforms and broader controller support; add audio monitoring, latency compensation, punch recording, and take comping.
3. Add custom audio fade shapes, comping, and portable media packaging or relinking.
4. Expand built-in processing, improve the real-time routing graph, and add effect parameter automation.
5. Add recovery and platform packaging.

The older JUCE-oriented files under `src/core` are excluded from the current build and need separate integration work before they can change any status above.
