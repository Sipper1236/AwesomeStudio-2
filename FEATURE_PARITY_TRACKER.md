## Next slices

1. Add VST3 audio-effect hosting and native plug-in editor windows; add more instrument presets and envelopes.
2. Add native MIDI input backends for other platforms and broader controller support; add audio monitoring, latency compensation, punch recording, and take comping.
3. Add freehand/Bezier audio fade drawing, comping, and portable media packaging or relinking.
4. Add plugin latency compensation and block-based CLAP processing.
5. Add platform packaging and broader migration tooling.

The older JUCE-oriented files under `src/core` are excluded from the current build and need separate integration work before they can change any status above.
