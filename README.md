# Awesome Studio

Awesome Studio is an early-stage digital audio workstation. The current executable has a Playlist with MIDI and WAV audio tracks, editable piano rolls, a built-in synth, a drum sequencer, basic track mixing, project save/load, and WAV render.

This is not feature parity with FL Studio, Reaper, or Ardour yet. The project is being built in vertical slices; [FEATURE_PARITY_TRACKER.md](FEATURE_PARITY_TRACKER.md) lists shipped behavior and outstanding work.

## Current workflow

- Add instrument tracks and patterns from the Browser or toolbar. Click an empty Playlist row to add a clip; drag clips in time or between tracks, and double-click a clip to open its piano roll.
- Choose one of seven factory synth presets in the Browser, then shape oscillator ADSR, pick a low-pass, high-pass, band-pass, or notch filter, and modulate its cutoff with a bipolar semitone ADSR envelope.
- Each drum-rack pad can use five WAV layers across velocity, with adjustable split points, per-pad waveform editors with draggable start/end boundaries for manual slicing, and layer-specific tuning, looping, and ADSR overrides; missing layers fall back to an assigned sample.
- Draw, move, resize, select, and delete notes across the full 128-note MIDI range in a scrollable piano roll. Shift-click to select notes for group movement.
- Double-click a note or choose **Edit → Note properties…** to enter exact pitch, start, length, velocity, and MIDI channel values. With several notes selected, the dialog can transpose them, shift their starts, or apply a shared length, velocity, or MIDI channel.
- Quantize selected note starts to the current piano-roll grid; when nothing is selected, quantize the whole clip. Quantize edits can be undone.
- Choose a root key and scale to highlight in-scale pitches; enable **Scale snap** to constrain newly drawn notes and keyboard auditions. Existing notes are left as they are.
- Select one or more piano-roll root notes, then use **Edit → Build chord from selection** to add major, minor, diminished, augmented, suspended, or seventh chords. Added notes copy the root notes' timing, velocity, and MIDI channel and can be undone.
- Toggle **Ghost notes** in the piano-roll toolbar to see faint, non-editable notes from other MIDI clips on the same track while editing the selected clip.
- Select chord notes with matching start and length, then use **Edit → Arpeggiate selected chord…** to choose up, down, or up/down direction, octave range, gate length, and source, fade, or repeating accent velocity patterns. The grid-timed conversion is one undoable edit.
- Use **Edit → Strum selected chord upward** to stagger selected chord tones slightly by pitch while preserving their lengths and velocities.
- Set straight, dotted, or triplet quarter through thirty-second note grids, edit velocity, and undo or redo note edits.
- Play and loop the full arrangement at 20–300 BPM.
- Enable an accented metronome and set a 1, 2, or 4 bar count-in. Count-in is included in full-arrangement WAV renders.
- Select an audio input and record a WAV take; with audio output connected, the take starts after count-in. With **Arm track** off it appears as a new Playlist track; with an Audio track armed it is added to that track. Recording also works without output, starting immediately. For a punch, enable **Punch**, set the IN and OUT beat positions, and record; the Playlist shades the range and the captured clip is trimmed to it. Set **COMP** in the Recording toolbar to move takes earlier with a positive value or later with a negative value; the offset is saved per input device.
- Turn on **Monitor audio** in the Recording toolbar to hear the selected input. With **Arm track** off, it goes straight to Master; select an Audio track and arm it to send input through that track’s level, pan, EQ, inserts, and mixer routing. Monitoring does not feed back into the recorded WAV.
- On Linux builds with ALSA development files, select a MIDI input and record note on/off and pitch-bend events into a bar 1 instrument pattern; count-in and looping follow the transport, and the take can be undone.
- Under **MIDI → Enable controller mappings**, listen for CC controls without recording notes. Use **MIDI → Learn controller for** to map a hardware control to master level, selected-track level/pan/mute/solo, tempo, synth-filter cutoff/resonance, synth amplitude-envelope ADSR, filter-envelope amount/ADSR/enable, or oscillator 2 mix. Mappings are channel-specific and saved in user settings.
- Turn on **Monitor MIDI** to play incoming notes on the selected synth or drum rack without recording. Monitoring supports overlapping notes, sample-loaded drum pads, and channel pitch bend for synth voices. Set the project-wide range from **MIDI → Set pitch-bend range…** (0.01–48 semitones); the setting is undoable, saved in the project, and written as MIDI RPN pitch-bend sensitivity on export. MIDI files with RPN sensitivity are imported with that range. Pitch bends are stored in clips and affect arrangement playback. Edit them in the piano roll's **Pitch Bend** lane below Velocity: click to add a point, drag to shape it, and right-click or press Delete to remove it. Monitoring can stay on while MIDI recording is armed.
- Set a common time signature and edit MIDI clip lengths in quarter-note beats.
- Set the project-start tempo in the transport, then right-click the Playlist ruler to add or change tempo markers; on a marker, choose **Ramp from previous tempo** for a linear BPM ramp or **Use a step change**. Tempo changes are undoable and drive the playhead, note and audio timing, automation, and WAV renders; MIDI export represents ramps with sampled tempo events.
- Choose sine, triangle, saw, or square for either synth oscillator. Enable a second oscillator with its own waveform, ±100-cent detune, and mix control; the patch is saved per track and used for audition, MIDI monitoring, arrangement playback, and WAV export.
- Enable a per-track low-pass, high-pass, band-pass, or notch synth filter with adjustable cutoff and resonance; it shapes note audition, live MIDI monitoring, arrangement playback, and WAV export.
- Shape each track's three-band crossover EQ and seven parametric bell bands with frequency, gain, Q, and a draggable response graph; the settings are saved and used in playback, WAV export, and stems.
- Shape each built-in Synth track with adjustable attack, decay, sustain, and release; the envelope is saved in the project and used for playback and WAV export.
- Add a drum rack with synthesized kick, snare, closed-hat, and open-hat voices, then program 8, 12, 16, 24, 32, 48, or 64 steps per bar. Right-click a step to set its velocity, trigger probability, or 1–8 ratchets; step edits, division changes, and piano-roll notes share undo and redo.
- Assign mono or stereo WAV samples to each drum pad across very-low, low, base, high, and very-high velocity ranges, with four editable split points. Missing layers fall back to an assigned sample; clearing the final sample restores the synthesized pad voice. Each layer can inherit the pad's tuning, sample start/end slice boundaries, ADSR, and note-held loop settings or override them independently. Select a layer in **Edit settings for** in the Browser to adjust its overrides.
- Import mono or stereo WAV audio as a Playlist track. Supported sources are PCM 8/16/24/32-bit or IEEE float32 WAV at 8–192 kHz; regions display a waveform and play in the arrangement and WAV export.
- Trim a loaded audio region from either edge by dragging its handle in the Playlist; the left edge updates the source offset and arrangement position together.
- Set fade-in and fade-out durations in beats and choose Linear, Smooth, Equal power, Custom power, or Drawn curves for the selected audio region. Custom power curves have an independent 0.25–4.00 exponent for each fade; 1.00 is linear, lower values rise or fall earlier, and higher values delay the transition. Choose **Drawn**, then hold Ctrl and drag across the fade line in the Playlist waveform to shape it; drawn curves are saved with the project, undoable, and used in playback and exports.
- To crossfade overlapping regions on the same audio track, select the earlier region and choose **Create crossfade with overlapping region** in the Audio Region panel. The incoming region must extend beyond the outgoing region; the paired equal-power fades render in playback and WAV exports and share undo/redo.
- Adjust track level, pan, mute, solo, and master level; watch per-track and master peak meters during playback and live MIDI monitoring.
- Add submixes with **Mixer → Add mixer bus**, route tracks from their Mixer **Output** selectors, and adjust each bus's level, pan, mute, solo, output, and peak meter. Set a bus output to another bus to build nested/group routes, or add bus auxiliary sends for parallel routing. Cyclic routes and sends are rejected. Removing a bus reroutes its outputs to its former parent.
- Add multiple **Aux sends** per track to feed mixer buses in parallel with the main output. Sends are post-track level, pan, EQ, and inserts, and respect destination bus mute and solo.
- Add multiple **Aux sends** per bus to feed other buses after the source bus level, pan, and inserts. Bus sends and parent routes share cycle prevention and follow solo/mute state through the routing graph.
- Add and reorder Delay, Reverb, Compressor, or Low-pass Filter inserts on tracks, buses, or Master. Their order and settings are saved with the project and run during realtime playback, WAV export, and stems.
- On Linux builds with Lilv development files, add realtime-safe LV2 audio effects to tracks, buses, or Master. The mixer exposes control ports, saves each plug-in identifier and parameter values, captures up to 1 MiB of plug-in-owned state per insert during save/autosave, and supports beat/value automation; inserts run in playback, WAV export, and stems.
- On Linux, add CLAP audio effects from `~/.clap`, `/usr/lib/clap`, `/usr/local/lib/clap`, or directories in `CLAP_PATH`. Awesome Studio supports mono or stereo effects with one main audio input and output, generic parameter controls and automation, and up to 1 MiB of plug-in-owned state per insert. CLAP processing currently runs one sample per process call; block processing and plug-in latency compensation remain open work.
- On Linux, add CLAP instruments from the same plug-in folders. Supported instruments have one CLAP note input, no audio inputs, and one mono or stereo main output. They play in arrangement playback and WAV export, respond to live MIDI, and can be auditioned from the piano roll and step sequencer. The Browser exposes generic controls for advertised parameters, with Playlist lanes and Touch, Latch, and Trim recording for instrument parameters. Native plug-in editors are not available yet.
- Enable Automation lanes in the Playlist toolbar and choose Volume, Pan, or an installed LV2/CLAP parameter from the lane selector. Plug-in lanes apply to tracks with the matching insert; other tracks show that the plug-in is not present. Click a lane to add a point, drag points to reshape it, and right-click or press Delete to remove a point. Select a keyframe in the Browser to set its segment to Linear, Smooth, Ease In, Ease Out, or Hold. Edits share undo/redo with the keyframe list; playback and WAV export use the selected segment shapes.
- Arm Write automation, choose Volume, Pan, or an LV2/CLAP parameter and Touch, Latch, or Trim, then move the matching Mixer control during playback. Trim adds the control movement as an offset to the existing curve. Touch commits after you stop moving the control; Latch keeps writing its last value until playback stops or Write is disarmed. Each pass is one undoable edit and is audible while recording.
- Import Standard MIDI Files (formats 0, 1, and 2 with PPQN or SMPTE timing), and export arrangements as format 0 single-track or format 1 multitrack MIDI, or stereo WAV at 44.1, 48, 88.2, 96, or 192 kHz in 16-bit PCM, 24-bit PCM, or 32-bit float, either as a full arrangement or a selected beat range. Integer PCM output can use TPDF dither.
- On Linux builds with libFLAC development files, use **File → Export arrangement to FLAC…** for full-song or beat-range lossless 16-bit or 24-bit stereo output, with optional TPDF dither.
- On Linux builds with libsndfile and Vorbis support, use **File → Export arrangement to Ogg Vorbis…** for full-song or beat-range stereo output with four variable-bitrate quality presets.
- On Linux builds with LAME/libmp3lame, use **File → Export arrangement to MP3…** for full-song or beat-range stereo output at 44.1 or 48 kHz and 128, 192, 256, or 320 kbit/s.
- Open **File → Render queue…** to add full-song or beat-range WAV and optional FLAC, Ogg Vorbis, or MP3 jobs, reorder them, and render them in sequence. Cancelling leaves the current output uncommitted and later jobs queued.
- Use **File → Export track stems…** to render every track to a separate stereo WAV in a folder, for either the full arrangement or a selected beat range. Choose the same sample format and dither options as the master WAV export. Range exports contain exactly the selected interval and cut effects tails at the boundaries. Each stem includes that track's EQ and effects, routed bus and Master effects, and level/pan automation plus the master level; mute and solo state do not omit tracks.
- Select any track and use **Track Equalizer** in the Browser to adjust each band's gain from −18 to +18 dB and move the low/mid and mid/high split frequencies. The EQ runs in realtime arrangement playback, full WAV exports, and track stems.
- Right-click the Playlist ruler to add a named arrangement marker or a tempo change; right-click either tag to edit or remove it. Left-click the ruler or a marker to seek and start playback. Marker and tempo edits can be undone and are saved in the project.
- Use **File → Save portable project copy…** to save an `.aws` copy beside a companion `<name>_media` folder. It copies referenced WAVs once and rewrites their paths relative to the copy; unavailable sources remain linked by their existing paths. Right-click an offline Playlist audio region and choose **Relink WAV…** to attach a replacement while preserving its arrangement timing and fades.
- Save and reopen `.aws` projects. Each save keeps up to three rotating `.aws.bakN` versions beside the project. Open one from **File → Open** to restore it as the current project. Dirty saved projects are autosaved to a `.autosave` sidecar every two minutes; opening a project offers recovery when that sidecar is newer, and saving the recovered project clears it. Dirty unsaved sessions are autosaved under the application data folder and offered for recovery at the next launch.
- Use the editor without an audio device; connect an output device to audition notes.

## Build

Requirements:

- CMake 3.16 or newer
- A C++17 compiler
- Qt 6.2 or newer with Widgets and Multimedia
- On Linux, libasound development files enable MIDI input recording, Lilv development files enable LV2 audio effects, libFLAC development files enable FLAC arrangement export, and libsndfile with Vorbis support enables Ogg Vorbis export, and libmp3lame enables MP3 export; all are optional. CLAP API headers are bundled under `third_party/clap`; audio-effect and instrument hosting use the system dynamic loader.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
./build/AwesomeStudio
```

On Windows, launch `build/AwesomeStudio.exe`. Qt's Multimedia backend uses the active platform audio service.

## Known gaps

Audio recording currently writes a separate WAV file per take, stores its path in the project, and loads the take into memory after recording. Live audio input monitoring works independently or during a take and routes directly to Master unless an Audio track is selected and **Arm track** is enabled; in that mode, the signal uses the track’s mixer path and meter. Takes are added to the armed track or to a new Playlist track when none is armed. Per-input manual take placement is available in milliseconds, but hardware latency is not measured automatically and take comping is not implemented. Live MIDI monitoring and recording use ALSA sequencer input on Linux builds; other platforms need native MIDI backends. Learnable MIDI CC and NRPN mappings currently cover master level, selected-track level and pan, selected-track mute and solo, synth-filter cutoff and resonance, synth amplitude-envelope attack/decay/sustain/release, filter-envelope amount/attack/decay/sustain/release/enable, oscillator 2 mix, and tempo. The synth provides seven factory presets, two oscillators, selectable low-pass, high-pass, band-pass, and notch filters, and bipolar filter-cutoff ADSR modulation; the track EQ has adjustable crossovers and seven parametric bell bands with a response graph, and the built-in Delay, Reverb, Compressor, and Low-pass Filter are compact first-party inserts; Bezier fade handles and streaming playback are not implemented; freehand fade curves are available in the Playlist. Linux builds can host realtime-safe LV2 effects and mono/stereo CLAP effects and instruments. Both formats expose generic parameter controls; Playlist automation targets effect and CLAP instrument parameters, and project files capture up to 1 MiB of plug-in-owned state per insert or instrument track on save/autosave. Portable copies do not collect external files referenced by plug-in state. CLAP currently processes one sample per call. VST3, native plug-in editor windows, and plug-in latency compensation remain unsupported. Track volume, pan, LV2/CLAP effect parameters, and CLAP instrument parameters have graphical lanes with Linear, Smooth, Ease In, Ease Out, and Hold segments and undoable keyframe editing; Touch, Latch, and Trim recording is available from Mixer controls for effect parameters and Browser instrument controls for CLAP instrument parameters. Drum pads support five velocity layers with configurable boundaries, independent tuning, loop and ADSR overrides, plus per-pad waveforms with draggable start/end boundaries for manual sample slices; automatic transient slicing, time-stretch, and modulation routing are not implemented. Autosave recovery covers both saved projects and unsaved sessions. Three rotating project backups are stored beside saved projects, but backup rotation is best-effort when the directory is not writable. Format 2 files with time-signature changes or different meters are not supported. Older JUCE-oriented source files remain in `src/core`, but the build does not include them and they are not shipped capabilities.
