# Awesome Studio

Awesome Studio is an early-stage digital audio workstation. The current executable has a Playlist with MIDI and WAV audio tracks, editable piano rolls, a built-in synth, a drum sequencer, basic track mixing, project save/load, and WAV render.

This is not feature parity with FL Studio, Reaper, or Ardour yet. The project is being built in vertical slices; [FEATURE_PARITY_TRACKER.md](FEATURE_PARITY_TRACKER.md) lists shipped behavior and outstanding work.

## Current workflow

- Add instrument tracks and patterns from the Browser or toolbar. Click an empty Playlist row to add a clip; drag clips in time or between tracks, and double-click a clip to open its piano roll.
- Draw, move, resize, select, and delete notes across the full 128-note MIDI range in a scrollable piano roll. Shift-click to select notes for group movement.
- Double-click a note or choose **Edit → Note properties…** to enter exact pitch, start, length, velocity, and MIDI channel values. With several notes selected, the dialog can transpose them, shift their starts, or apply a shared length, velocity, or MIDI channel.
- Quantize selected note starts to the current piano-roll grid; when nothing is selected, quantize the whole clip. Quantize edits can be undone.
- Choose a root key and scale to highlight in-scale pitches; enable **Scale snap** to constrain newly drawn notes and keyboard auditions. Existing notes are left as they are.
- Select one or more piano-roll root notes, then use **Edit → Build chord from selection** to add major, minor, diminished, augmented, suspended, or seventh chords. Added notes copy the root notes' timing, velocity, and MIDI channel and can be undone.
- Toggle **Ghost notes** in the piano-roll toolbar to see faint, non-editable notes from other MIDI clips on the same track while editing the selected clip.
- Select chord notes with matching start and length, then use **Edit → Arpeggiate selected chord…** to choose up, down, or up/down direction, octave range, gate length, and source, fade, or repeating accent velocity patterns. The grid-timed conversion is one undoable edit.
- Use **Edit → Strum selected chord upward** to stagger selected chord tones slightly by pitch while preserving their lengths and velocities.
- Set straight, dotted, or triplet quarter through thirty-second note grids, edit velocity, and undo or redo note edits.
- Play and loop the full arrangement at 20–300 BPM.
- Enable an accented metronome and set a 1, 2, or 4 bar count-in. Count-in is included in full-arrangement WAV renders.
- Select an audio input and record a WAV take; with audio output connected, the take starts after count-in, then appears as a new Playlist track. Recording also works without output, starting immediately.
- Turn on **Monitor audio** in the Recording toolbar to hear the selected input through the master output, either on its own or during recording. Monitoring does not feed back into the recorded WAV; starting a take stops standalone monitoring.
- On Linux builds with ALSA development files, select a MIDI input and record note on/off and pitch-bend events into a bar 1 instrument pattern; count-in and looping follow the transport, and the take can be undone.
- Under **MIDI → Enable controller mappings**, listen for CC controls without recording notes. Use **MIDI → Learn controller for** to map a hardware control to master level, selected-track level or pan, or tempo. Mappings are channel-specific and saved in user settings.
- Turn on **Monitor MIDI** to play incoming notes on the selected synth or drum rack without recording. Monitoring supports overlapping notes, sample-loaded drum pads, and channel pitch bend for synth voices. Set the project-wide range from **MIDI → Set pitch-bend range…** (0.01–48 semitones); the setting is undoable, saved in the project, and written as MIDI RPN pitch-bend sensitivity on export. MIDI files with RPN sensitivity are imported with that range. Pitch bends are stored in clips and affect arrangement playback. Edit them in the piano roll's **Pitch Bend** lane below Velocity: click to add a point, drag to shape it, and right-click or press Delete to remove it. Monitoring can stay on while MIDI recording is armed.
- Set a common time signature and edit MIDI clip lengths in quarter-note beats.
- Choose sine, triangle, saw, or square for either synth oscillator. Enable a second oscillator with its own waveform, ±100-cent detune, and mix control; the patch is saved per track and used for audition, MIDI monitoring, arrangement playback, and WAV export.
- Enable a per-track synth low-pass filter with adjustable cutoff and resonance; it shapes note audition, live MIDI monitoring, arrangement playback, and WAV export.
- Shape each built-in Synth track with adjustable attack, decay, sustain, and release; the envelope is saved in the project and used for playback and WAV export.
- Add a drum rack with synthesized kick, snare, closed-hat, and open-hat voices, then program 8, 12, 16, 24, 32, 48, or 64 steps per bar. Right-click a step to set its velocity, trigger probability, or 1–8 ratchets; step edits, division changes, and piano-roll notes share undo and redo.
- Assign a mono or stereo WAV sample to each of the drum rack's four pads; clearing a pad restores its synthesized sound. Optionally load low- and high-velocity sample layers per pad, each with its own velocity threshold. Tune each pad by up to ±24 semitones, choose a 0–99% start position, shape it with a per-pad ADSR envelope, and optionally loop it during pad audition, live MIDI, arrangement playback, and WAV export.
- Import mono or stereo WAV audio as a Playlist track. Supported sources are PCM 8/16/24/32-bit or IEEE float32 WAV at 8–192 kHz; regions display a waveform and play in the arrangement and WAV export.
- Trim a loaded audio region from either edge by dragging its handle in the Playlist; the left edge updates the source offset and arrangement position together.
- Set fade-in and fade-out durations in beats and choose Linear, Smooth, Equal power, or Custom power curves for the selected audio region. Custom power curves have an independent 0.25–4.00 exponent for each fade; 1.00 is linear, lower values rise or fall earlier, and higher values delay the transition.
- To crossfade overlapping regions on the same audio track, select the earlier region and choose **Create crossfade with overlapping region** in the Audio Region panel. The incoming region must extend beyond the outgoing region; the paired equal-power fades render in playback and WAV exports and share undo/redo.
- Adjust track level, pan, mute, solo, and master level; watch per-track and master peak meters during playback and live MIDI monitoring.
- Add submixes with **Mixer → Add mixer bus**, route tracks from their Mixer **Output** selectors, and adjust each bus's level, pan, mute, solo, output, and peak meter. Set a bus output to another bus to build nested/group routes, or add bus auxiliary sends for parallel routing. Cyclic routes and sends are rejected. Removing a bus reroutes its outputs to its former parent.
- Add multiple **Aux sends** per track to feed mixer buses in parallel with the main output. Sends are post-track level, pan, EQ, and inserts, and respect destination bus mute and solo.
- Add multiple **Aux sends** per bus to feed other buses after the source bus level, pan, and inserts. Bus sends and parent routes share cycle prevention and follow solo/mute state through the routing graph.
- Add and reorder Delay, Reverb, Compressor, or Low-pass Filter inserts on tracks, buses, or Master. Their order and settings are saved with the project and run during realtime playback, WAV export, and stems.
- On Linux builds with Lilv development files, add realtime-safe LV2 audio effects to tracks, buses, or Master. The mixer exposes control ports, saves the plugin URI and parameter values with the project, and lets you add beat/value keyframes from each control’s Automation editor; inserts run in playback, WAV export, and stems.
- Enable Automation lanes in the Playlist toolbar to show track volume or pan. Click a lane to add a point, drag points to reshape it, and right-click or press Delete to remove a point. Edits share undo/redo with the keyframe list; playback and WAV export interpolate linearly.
- Arm Write automation, choose Volume or Pan and Touch, Latch, or Trim, then move the matching Mixer control during playback. Trim adds the control movement as an offset to the existing curve. Touch commits when you release the control; Latch keeps writing its last value until playback stops or Write is disarmed. Each pass is one undoable edit and is audible while recording.
- Import Standard MIDI Files (formats 0 and 1 with PPQN timing), and export arrangements as multitrack MIDI or stereo WAV at 44.1, 48, 88.2, 96, or 192 kHz in 16-bit PCM, 24-bit PCM, or 32-bit float, either as a full arrangement or a selected beat range. Integer PCM output can use TPDF dither.
- Use **File → Export track stems…** to render every track to a separate stereo WAV in a folder, for either the full arrangement or a selected beat range. Choose the same sample format and dither options as the master WAV export. Range exports contain exactly the selected interval and cut effects tails at the boundaries. Each stem includes that track's EQ and effects, routed bus and Master effects, and level/pan automation plus the master level; mute and solo state do not omit tracks.
- Select any track and use **Track Equalizer** in the Browser to adjust low (below 120 Hz), mid (120 Hz–6 kHz), and high (above 6 kHz) bands from −18 to +18 dB. The EQ runs in realtime arrangement playback, full WAV exports, and track stems.
- Right-click the Playlist ruler to add a named arrangement marker; right-click a marker to rename or remove it. Left-click the ruler or a marker to seek and start playback. Marker edits can be undone and are saved in the project.
- Use **File → Save portable project copy…** to save an `.aws` copy beside a companion `<name>_media` folder. It copies referenced WAVs once and rewrites their paths relative to the copy; unavailable sources remain linked by their existing paths. Right-click an offline Playlist audio region and choose **Relink WAV…** to attach a replacement while preserving its arrangement timing and fades.
- Save and reopen `.aws` projects. Each save keeps up to three rotating `.aws.bakN` versions beside the project. Open one from **File → Open** to restore it as the current project. Dirty saved projects are autosaved to a `.autosave` sidecar every two minutes; opening a project offers recovery when that sidecar is newer, and saving the recovered project clears it. Dirty unsaved sessions are autosaved under the application data folder and offered for recovery at the next launch.
- Use the editor without an audio device; connect an output device to audition notes.

Version 35 project files are JSON written atomically and store per-note trigger probability and ratchet counts, per-clip step divisions, and per-pad low- and high-velocity sample layers, ADSR envelopes, and loop settings alongside sample tuning and start positions plus per-track synth-filter and dual-oscillator settings, up to 1,000 named arrangement markers, per-track three-band EQ, mixer buses with parent routes and auxiliary sends, multiple track auxiliary sends, audio fade curves, the project-wide MIDI pitch-bend range, per-clip pitch-bend events and custom fade-shape exponents, and up to eight built-in or LV2 plug-in inserts per mixer channel (48 inserts per project); LV2 inserts save the plugin URI and generic control-port values plus per-control beat/value automation curves. Version 34 and older files default plugin automation to empty; version 33 and older files have no LV2 inserts. Version 32 and older files default custom fade exponents to 1.0; version 31 and older files default low-velocity layers off; version 30 and older files default pad envelopes to 8 ms attack, 0 decay, full sustain, and 60 ms release; version 29 and older files default the high-velocity layer off; version 28 and older files default ratchets to one hit; version 27 and older files default note probability to 100%; version 26 and older files default sample loops off; version 25 and older files default clip divisions to 16 steps per bar; version 24 and older files default drum sample tuning and start positions to neutral; version 23 and older files default the synth filter off; version 22 and older files default the second oscillator off; version 21 files retain their existing data and default to a two-semitone pitch-bend range; version 20 files retain existing project data and load with empty pitch-bend event lists; version 19 files retain their Delay, Reverb, and Compressor chains with a default low-pass configuration; version 18 files migrate with empty effect chains; version 17 projects retain their multiple track sends and nested bus routes; version 16 projects migrate their single track send and route buses to Master; version 15 projects default fades to linear; version 14 projects migrate with sends off; version 13 projects migrate with no buses and all tracks routed to Master; version 12 projects also gain flat (0 dB) EQ settings; version 11 projects gain an empty marker list. Versions 1–10 migrate with compatible synth-envelope, meter, metronome, count-in, automation, and default MIDI-channel values. MIDI notes retain their zero-based channel through ALSA recording, project save/load, and Standard MIDI File import/export; notes created in the app use the instrument track's export channel. Pitch-bend events are stored with each MIDI clip and use the configured range during live monitoring and arrangement playback. Track volume and pan automation is stored as beat/value keyframes. Audio clips and drum pads store source WAV paths (absolute in regular projects and relative in portable copies); missing or unsupported sources reopen offline. Regular `.aws` files do not package media; portable copies put referenced WAVs in a sibling `<name>_media` folder. Sources are loaded into memory, limited to 128 MiB per WAV, 40 million decoded samples per source, and 512 MiB of decoded audio per project. MIDI import reads note, channel pitch-bend, and RPN pitch-bend sensitivity events plus the first tempo and time-signature events in format 0 or 1 PPQN files, and maps channel 10 tracks to the drum rack. MIDI export writes a format 1 file with a conductor track, pitch-bend sensitivity RPN events, and unassigned drum-rack notes on channel 10. WAV export renders synths with their ADSR envelopes, oscillator stacks, per-track low-pass filters, track EQ/automation/inserts, routed bus and Master inserts, synthesized or sampled drums with note probabilities, ratchets, low-, base-, and high-velocity layers, per-pad ADSR envelopes, tuning, start positions, and note-held loop playback, imported audio with region fades and track processing, metronome, and configured count-in at the selected 44.1, 48, 88.2, 96, or 192 kHz rate; full-arrangement exports include insert tails, while beat-range exports stop at their boundaries.

## Build

Requirements:

- CMake 3.16 or newer
- A C++17 compiler
- Qt 6.2 or newer with Widgets and Multimedia
- On Linux, libasound development files enable MIDI input recording, and Lilv development files enable LV2 audio effects; both dependencies are optional.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
./build/AwesomeStudio
```

On Windows, launch `build/AwesomeStudio.exe`. Qt's Multimedia backend uses the active platform audio service.

## Known gaps

Audio recording currently writes a separate WAV file per take, stores its path in the project, and loads the take into memory after recording. Live audio input monitoring routes directly to Master and works independently or during a take; there is no latency compensation or track-armed input monitoring. Live MIDI monitoring and recording use ALSA sequencer input on Linux builds; other platforms need native MIDI backends. Learnable MIDI CC mappings currently cover master level, selected-track level and pan, and tempo. The track EQ is a basic three-band equalizer, and the built-in Delay, Reverb, Compressor, and Low-pass Filter are compact first-party inserts; there is no punch recording, freehand/Bezier audio fade drawing, or streaming playback. Linux builds can host realtime-safe LV2 audio effects with Lilv, but VST3/CLAP, plugin instruments and editor windows, plugin state beyond control values, and graphical Playlist lanes for plugin parameters remain unsupported. Track volume and pan automation has graphical linear lanes, undoable keyframe editing, and touch/latch recording from Mixer controls; curved segments and graphical plugin automation lanes remain future work. Drum pads support a base sample plus optional low- and high-velocity layers; all three use the same tuning, start, loop, and per-pad ADSR envelope settings. Autosave recovery covers both saved projects and unsaved sessions. Three rotating project backups are stored beside saved projects, but backup rotation is best-effort when the directory is not writable. MIDI format 2 and SMPTE-timed files are not supported. Older JUCE-oriented source files remain in `src/core`, but the build does not include them and they are not shipped capabilities.
